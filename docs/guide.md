# 使い方

## 原稿から書き出す

空の原稿では「サンプル」から、新美南吉「[ごん狐](https://www.aozora.gr.jp/cards/000121/card628.html)」を開けます。六章・ルビ・圏点を含む青空文庫版の全文です。[底本と収録時の変更](../public/samples/gongitsune-notice.txt)。

1. 原稿を貼り付けるか、「読み込む」からTXT・Markdown・Wordを開きます。
2. 紙面を見ながら「本」で判型や余白を選びます。文字の共通設定は「編集」にあります。
3. 必要なページを「構成」から加えます。並べ替えはドラッグ、複製・削除は行の「…」です。
4. 「書き出す」からPNG・PDFを保存します。

「見開きで組む」は左右の余白と章の開始面を冊子向けに扱います。「一枚ずつ組む」は各ページで同じ余白を使います。プレビューの見開き・単ページ表示とは独立した設定です。

SNS向けのサイズは「一枚ずつ組む」の画像レイアウトから選べます。正方形、4:5、16:9を用意しています。

## 文字と書式

見出し、ルビ、圏点、改ページ、改丁は原稿上のボタンから指定できます。入力する記法は操作ガイドの「原稿の書き方」でも確認できます。

| 記法 | 表現 |
| --- | --- |
| `# 章` / `## 節` / `### 小見出し` | 見出し1〜3 |
| `｜漢字《かんじ》` | ルビ |
| `*言葉*` / `**言葉**` | 圏点 / 太字 |
| `[言葉]{.dot}` / `.circle` / `.triangle` | 丸 / 白丸 / 三角の圏点 |
| 独立した行の `---` | 改ページ |
| `:::recto` | 改丁 |
| `> 文章` | 引用 |

改丁は次の奇数ページから始め、必要なら白ページを挟みます。見出しだけでは改ページしません。字下げは原稿の全角空白を使い、空行も残します。

```text
:::center
中央に置く文章
:::
```

揃えや段落の書式は、原稿で範囲を選んで「範囲」から変更できます。選択した文字だけの指定は「文字」、本全体や見出しの統一は右側の「編集」で対象を選びます。GUIで付けた局所書式も原稿に現れます。

文字の詳細指定には `[12]{numbers="tcy"}`、`[HTML]{orientation="upright"}`、`[言葉]{fontPt="12"}` などがあります。段落や章の細かい設定はGUIを使うと対応する `:::format` / `:::section` が入ります。

記号をそのまま表示するには直前に `\` を付けます。Markdownのリスト・表・リンク・画像は構造化せず本文に残します。対応範囲を絞った記法で、CommonMark全体の実装ではありません。

## 書体と色

「本 → 書体と配色」で全体の書体と配色を変えられます。Noto Serif JP、しっぽり明朝、源暎こぶり明朝、ZENオールド明朝、Noto Sans JP、ZEN角ゴシック New、ZEN丸ゴシックを同梱しています。書体は端末内で読み込み、使ったものを制作データZIPにも含めます。

本文・見出し1〜3・引用は「編集」で対象を選び、ノンブル・柱・自由ページの文字はそれぞれの設定から別の書体を指定できます。「基本の書式に従う」に戻すと継承します。局所指定は `[文字]{fontFamily="Shippori Mincho"}` のように原稿にも残ります。

配色は8種類から選べます。「色を個別に調整」を開くと、紙色と文字色を別々に選ぶかRGBで指定できます。読みにくい組み合わせには調整ボタンが出ます。初期値は白い紙と墨色の文字です。取り込んだ画像・PDFの色は素材のままです。

## 構成と素材

表題紙・章扉・奥付は自由ページのテンプレートです。文字・画像・線・矩形を編集できます。紙面上のドラッグやサイズ変更、複数選択、整列、固定、重なり順の変更に対応します。

自動目次は見出しとノンブルを更新します。「ノンブル」は紙面に印字する番号です。画面上の通しページとは別に、表示の有無、開始番号、章ごとの番号系列を設定できます。「本の仕上げ」では末尾に白ページを加えて総ページ数をそろえられます。

素材はPNG・JPEG・静的SVG・PDFを端末から読み込みます。PDFはページ範囲を選んで挿入でき、差し替えても使用箇所を保ちます。自由配置は自由ページに限り、通常の本文は自動で組みます。

Wordは文章・見出し・ルビ・圏点・手動改ページを取り込みます。元の余白や書体、画像、注本文、変更履歴の再現には対応していません。TXTは文字コードを判定し、平文として取り込みます。

## 出力

- PNGは表示ページ、見開き、全ページ・範囲ZIP。通常は300dpi、画像レイアウトは選んだ画素数で保存します。
- 閲覧用PDFは同じ紙面に目次リンクと見出しのしおりを加えます。
- 印刷用PDFは塗り足し0〜10mm、トンボ、300/350/600dpi、RGBまたはグレースケールを指定できます。仕上がりを拡大せず、外側に用紙を足します。

モノクロ本文の初期値は600dpi・グレースケール・各辺3mm・トンボなし、カラーは350dpi・RGBです。商品によって条件が異なるので、印刷所の指定を優先してください。

素材PDFの「元の文字・図形を保持」はRGBで使えます。注釈・フォーム付きPDFと、グレースケールとの併用には対応していません。本文はこの設定でも画像です。

はみ出しや素材不足は出力前に確認できます。低い解像度や足りない塗り足しを自動で補う機能ではありません。PDF/X・ICC色管理・CMYK変換、本文の検索可能な文字PDFは未対応です。

## 作業を残す

書名を押すと、新規作成・ファイルを開く・作業の保存・作品情報が出ます。作業JSONは本文・書式・構成・素材を含みます。制作データZIPはこれに原稿と素材原本、設定、同梱書体をまとめます。再開に使う正本はZIP内のbook.jsonです。

自動保存は同じブラウザーの端末内にあります。別の端末やブラウザーとは共有されません。競合・容量不足・破損を検出した場合は元データを上書きせず停止します。保存状態を確認し、大切な作業はファイルでも保存してください。

作業JSONは現在のschemaVersion 3、制作データZIPはcompholio-production形式だけを開きます。旧形式の自動移行は行いません。入力中の不完全な記法は保護し、確定するまで画像の書き出しを待ちます。

## キーボード

CtrlはmacOSではCmdです。

| 操作 | キー |
| --- | --- |
| 操作検索 | Ctrl + K |
| 開く / 作業JSONを保存 | Ctrl + O / S |
| 本文の検索 / 置換 | Ctrl + F / H |
| 元に戻す / やり直す | Ctrl + Z / Shift + Z |
| 太字 | Ctrl + B |
| 改ページ / 改丁 | Ctrl + Enter / Shift + Enter |
| 見出し1〜3 | Ctrl + Alt + 1〜3 |
| 構成を移動 / 項目メニュー | Alt + ↑↓ / Shift + F10 |
| 紙面に集中 | Ctrl + Shift + F |

自由ページでは矢印で1mm、Shiftと併用して10mm移動します。Ctrl + Dで複製、Deleteで削除、Tabで要素移動、Escapeで選択を解除します。

縦書きでは括弧・句読点・小書き文字に同梱書体の縦用字形を使います。三点・二点リーダーは中央へ縦に並べ、ダッシュ（―、—、–、‒、⸺、⸻、︱、︲）は長さに応じて接続します。ハイフン・マイナス・長音は別の文字として扱います。

## 制約

原稿は50万UTF-16単位、素材100件、特殊ページ200件、自由ページの要素50件までです。原本素材は1件16MiB、PDFは20ページ、出力画像の圧縮データ合計は128MiBまでです。上限付近では範囲を分けて書き出してください。

各書体は標準の太さを収録し、太字は描画時の合成です。高度なルビ、後注・相互参照、任意のローカル書体、表紙・背幅の設計は未対応です。スマホ幅の操作とFirefox/WebKitを自動検査していますが、iOS/Android実機や全ての日本語入力環境を確認したものではありません。
